# Musiche ambientali della Taverna

Otto brevi composizioni strumentali originali, sintetizzate per questa applicazione.
Nessuna registrazione, melodia o campione di terze parti è incorporato.
Generate da `scripts/build-ambient-audio.py` (Python, numpy, ffmpeg), disponibili
localmente per evitare collegamenti esterni scaduti e blocchi anti-hotlink.
Si applica la licenza MIT del progetto. Il player mantiene anche il caricamento
privato dei file audio dell'utente, senza inviarli al server.
