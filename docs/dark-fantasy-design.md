# Dark fantasy amethyst redesign

Direction requested: 60% dark fantasy, 30% medieval core, 10% maximalism. This replaces the previous separate visual worlds while preserving the amethyst identity and application functionality.

Typography: Alegreya (body and controls), Unifraktur Maguntia (display headings), functional Georgia suit/chess glyphs. Primary UI headings use sentence case where possible.

## Original artwork

Tool: built-in `image_gen.imagegen`.

Production asset: `public/assets/worlds/dark-fantasy-triptych.webp` (1536 × 1024, approximately 265 KB). A single image is reused, with CSS crops for the three home portals. Original PNG is retained in the local Codex generated-images directory.

Generation brief: Original landscape triptych with three equally sized vertical subjects: a medieval gauntlet holding playing cards; a carved chess knight and die among Gothic ruins; an armored knight with a sword under an amethyst eclipse. Dark fantasy 60%, medieval engraved aesthetic 30%, restrained ornate detail 10%. Blackened steel, aged ivory and amethyst; dramatic shadow, etched textures. No text, watermarks or UI.
